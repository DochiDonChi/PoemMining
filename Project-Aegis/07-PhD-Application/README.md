# PhD Application Workspace

## Purpose

This folder tracks the PhD application work for Project Aegis.

Core positioning:

> Trustworthy AI Investment Research: reproducible, auditable, evidence-grounded, risk-aware investment research agents.

## Strategy

Do not mass email professors. Build a targeted supervisor list, verify each professor from official sources, then send tailored emails.

## Files

- `Supervisor-Database-v0.1.csv` — target supervisors and fit scores.
- `Contact-Log-v0.1.csv` — outreach and follow-up records.
- `Funding-Tracker-v0.1.md` — scholarships and funding notes.
- `University-Comparison-v0.1.md` — university and department comparison.
- `Application-Timeline-v0.1.md` — application roadmap.
- `Research-Proposal-Outline-v0.1.md` — proposal structure.
- `Email-Templates/` — outreach templates.

## Current rule

Supervisor names, emails, and funding status must be verified from official university pages before outreach.
