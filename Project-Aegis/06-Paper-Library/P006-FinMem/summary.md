# P006 Summary — FinMem

## Paper

**FinMem: A Performance-Enhanced LLM Trading Agent with Layered Memory and Character Design**

## Why this paper matters

P006 matters because it focuses on memory in financial agents. Project Aegis needs this line of research because investment research is not a one-shot task. A credible research agent needs memory of past theses, company events, macro regimes, mistakes, and portfolio context.

## One-sentence summary

P006 proposes an LLM-based trading agent that uses layered memory and character design to improve financial decision-making.

## What you should understand after reading it

After reading this paper, you should be able to explain:

1. Why memory matters for financial agents.
2. What layered memory means.
3. How memory can improve decision-making.
4. Why memory can also create risk, such as stale beliefs and anchoring.
5. How Project Aegis can extend trading memory into investment thesis memory.

## Key Project Aegis use

Use P006 to support the memory-agent pillar.

Do **not** use P006 as proof that memory-based agents are trustworthy. It is mainly a trading-agent paper, and memory auditability remains a major open question.

## Reading priority

Medium-high. Read after P004 if you want to understand memory-based financial agents.
