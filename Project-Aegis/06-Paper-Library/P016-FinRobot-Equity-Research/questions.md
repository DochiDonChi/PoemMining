## Evaluation questions

## Auditability questions

1. Can every claim in the generated report be traced to source evidence?
2. Are valuation assumptions explicitly listed?
3. Does the system show contrary evidence?
4. Does it record reasoning steps?
5. Does it allow human review or override?

2. What makes it different from a financial QA system?

4. What is still missing before institutional use?
5. How can Project Aegis extend this paper?

## Project Aegis answer target

After reading P016, you should be able to say:

> P016 is important because it shifts the financial-agent discussion from trading actions toward equity research artifacts. It supports the idea that investment research agents are an emerging category, but it also exposes the need for stronger evaluation, auditability, and evidence tracing.
