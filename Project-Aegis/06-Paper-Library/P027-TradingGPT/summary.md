# P027 Summary — TradingGPT

## Paper

**TradingGPT: Multi-Agent System with Layered Memory and Distinct Characters for Enhanced Financial Trading Performance**

## Why this paper matters

P027 matters because it is an early memory-based multi-agent trading paper related to the FinMem line of work. It helps Project Aegis understand how layered memory and character-based agents evolved in financial trading systems.

## One-sentence summary

P027 proposes a multi-agent trading system using layered memory and distinct agent characters to improve financial trading performance.

## What you should understand after reading it

After reading this paper, you should be able to explain:

1. What TradingGPT is.
2. How it relates to FinMem.
3. Why layered memory matters.
4. Why character design is used.
5. How Project Aegis can extend trading memory into investment research memory.

## Key Project Aegis use

Use P027 as a candidate background paper for memory-based multi-agent trading systems.

Do **not** use P027 as proof that research memory is solved. It is trading-focused and requires full-text verification.

## Reading priority

Medium. Read after P006 and P026 if you want to understand the memory-agent lineage.
