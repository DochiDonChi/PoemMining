# Mobile Reading Guide

## Purpose

This guide explains how to read Project Aegis papers on a phone.

The goal is not to read papers like raw PDFs. The goal is to read each paper like a short mobile-friendly learning book.

## Recommended mobile reading format

Each important paper should eventually follow this structure:

```text
PXXX-Paper-Name/
  ebook.md
  summary.md
  questions.md
  notes.md
  figures.md
  tables.md
  project-aegis-relevance.md
```

The most important mobile file is:

```text
ebook.md
```

This file should be readable from top to bottom on a phone.

## Standard ebook structure

Each `ebook.md` should contain:

1. Why this paper matters
2. What problem the authors solve
3. The main idea in plain language
4. Key concepts
5. Method / system architecture
6. Dataset and experiment design
7. Main results
8. Limitations
9. What Project Aegis can learn
10. Supervisor-style questions
11. What to read next

## How to study on phone

Use this sequence:

1. Open `06-Paper-Library/README.md`.
2. Choose a paper folder.
3. Open `ebook.md` first.
4. Read one chapter at a time.
5. If confused, open `summary.md`.
6. After reading, open `questions.md` and test yourself.
7. Return to ChatGPT and say: `开始领读 P001` or the paper ID you want.

## Current first reading path

Read in this order:

1. P001 Agentic Trading
2. P016 FinRobot Equity Research
3. P025 FinRpt
4. P013 Finance Agent Benchmark
5. P014 Evaluation and Benchmarking Suite

## Important rule

Do not try to finish a paper in one sitting.

On a phone, one chapter per session is enough. The goal is repeated exposure and understanding, not speed.
