## What became stronger

### Better mobile learning experience

The user can now read the priority papers in a phone-friendly bilingual format.

### Better English learning

Each chapter includes English explanation and key vocabulary, making the library useful not only for research but also for academic English training.

### Better PhD interview preparation

The bilingual files help the user explain Project Aegis in both Chinese and English.
